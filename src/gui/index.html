📤 提交任务到服务器

装过依赖（torch 等）的环境要选对，否则会报 ModuleNotFoundError。会按项目记住你的选择。
在项目文件夹里执行的命令，和你在自己电脑的终端里敲的一样。点上面的文件名可以直接填好。
每 30 秒看一次，凑够就用最空的那几张卡开跑。关掉网页也会继续等，但别退出 yunpao ui。
只能用英文字母、数字、- 和 _。之后看日志、停止任务都用这个名字。

⬇ 从服务器取回结果

任务在服务器上生成的文件（模型、图片、表格…）会列在这里。标「新」的是你电脑上还没有的。

⌨ 服务器终端

直接在服务器上敲命令，打开时已经在这个项目的代码目录里。关掉这个窗口不会断开（再点「⌨ 终端」回来）；要跑很久的训练，用「📤 提交任务」更稳，网页关了也不会停。

🔑 登录服务器

填管理员发给你的信息就行，一般长这样：ssh -p 22326 zhangsan@202.120.38.31 → 地址 202.120.38.31，端口 22326，用户名 zhangsan。
用密钥登录的服务器可以不填密码。密码只用这一次，不会保存。登录后 4 小时内不用再输；过期了再点「登录」就行。

从 SSH 配置导入服务器

这些是你电脑上 ~/.ssh/config 里已有的服务器。勾选后导入，yunpao 会沿用你原来的 SSH 设置（密钥、端口等），不用重新配置。

⚙ AI 设置

填好 API Key 后，右侧的 AI 助手和 yunpao ask 命令就能用了。只需要设置一次。
你目前用的是终端里的环境变量 OPENAI_API_KEY。在这里保存后，会优先使用这里的设置。
一般以 sk- 开头。只保存在你这台电脑上，不会上传。
每次和 AI 对话时，会把这些发给上面的 AI 服务：服务器名称、显卡占用（别人的进程只发用户名和程序名，不发完整命令）、你自己任务的最近几行日志、项目里的脚本名。AI 分析失败原因时，还会发你自己的报错日志和出错位置附近的代码。
不确定就用默认的第一个。
